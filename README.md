# Owolabi_ohms_law_calculator
Ohm's Law and Power Calculator

What it does

This Python program calculates voltage, current, resistance, and
electrical power. The user selects a calculation from a menu, enters the
known values, and receives the result with the appropriate unit.

How to run it

Install Python 3, then run:

``` bash
python ohms_law.py
```

You can also open and run `ohms_law.py` in Pydroid 3 on Android.

My own twist

I added a calculation history feature. It stores the results of
calculations made during the current program session and allows the user
to view them later.
